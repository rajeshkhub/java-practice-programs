# Patterns

This folder contains pattern programs created to improve understanding of loops.

## Problems Practiced
* Pyramid pattern
* Inverted Pyramid
* Daimond shape pattern
* Hollow Square
* Hollow pyramid

## Concepts Covered
* Inverted pattern
* Nested for loops
* Iteration using a variable
* for loops
* if-else inside loops
* row/column logic

## Goal
Build strong logic and loop mastery before moving to Arrays, DSA, and advanced problem-solving.
