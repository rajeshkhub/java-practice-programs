# Loops

This folder contains Java programs that focus on repetition, iteration, and number-based problem solving using loops.

## Problems Practiced
* Factorial
* Fibonacci Series
* * Palindrome Number
* Sum of Digits
  
## Concepts Covered
* Loop Traversal
* Nested Loops
* Digit Extraction
* Number Manipulation
* Mathematical Logic
* Iterative Problem Solving

## Goal
The purpose of these programs is to strengthen understanding of loops, improve logical thinking, and build a foundation for more advanced programming concepts.
