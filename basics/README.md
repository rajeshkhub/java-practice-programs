# Basics

This folder contains Java programs that focus on fundamental programming concepts and problem-solving techniques.

## Problems Practiced
* Calculator
* Largest Number
* Odd or Even Number
* Prime Number
* Swapping Two Numbers

## Concepts Covered
* Variables and Data Types
* Arithmetic Operations
* Conditional Statements
* User Input Handling
* Number Comparison
* Basic Mathematical Logic

## Goal
The purpose of these programs is to build a strong foundation in Java programming, develop logical thinking, and prepare for more advanced topics such as loops, arrays, strings, and Data Structures & Algorithms.
