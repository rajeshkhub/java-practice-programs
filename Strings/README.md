# Strings

This folder contains Java programs that focus on string manipulation, character processing, and text-based problem solving.

## Problems Practiced
* Count Digits in a String
* Reverse String
* Vowel Count
* Anagram check
* Duplicate Characters remover
* First non repeating character finder

## Concepts Covered
* String Traversal
* Character Processing
* String Manipulation
* Character Counting
* Conditional Logic
* Iterative Problem Solving
* Character frequency
* Case insensitive comparison
* StringBuilder

## Goal
The purpose of these programs is to strengthen understanding of strings, improve text-processing skills, and build a foundation for advanced string algorithms and problem solving.
